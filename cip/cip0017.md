# CIP-0017: Soft-throughout topic geometry (MPPCA topics; harden only at LLM/report boundaries)

## Summary

Replace early hard k-means as the primary phrase→topic state with a **mixture of probabilistic PCA (MPPCA)** whose component means are **k-means initialised**, keep **soft responsibilities** through document histograms, framing profiles, and transport, and **harden only** when a discrete interface is required (LLM labelling / lens-partition prompts, named theme tables, prose). Soft lens mixture weights (topic→lens PPCA + σ²\* by EMD) and document EMD remain, but they consume the soft topic geometry rather than hard `cluster_id` lookups on sklearn centroids.

This implements [REQ-000A](../requirements/req000A_soft-throughout-topic-geometry.md). Library primitives should land in **multilogue** (extending CIP-0001 cluster / CIP-0005 soft); pub-dialogue thins onto them.

## Motivation

Today's Address stack already depends on soft assignment and EMD for headline analyses:

1. **Soft lenses** — PPCA Gaussian per framing lens; Bayes weights of *topic centroids* over lenses; σ²\* by mean EMD across LLM lens runs.
2. **Document distance** — EMD between documents as distributions over *topics*, cosine ground cost on centroids.

But phrase→topic is still hardened at k-means. Softness is re-introduced only at the lens layer via `mixture_weights[cluster_id]`. That split causes:

- **Centroid definition bugs** — fresh `KMeans.cluster_centers_` vs freeze-path member means (~1e-7 after L2 norm) flipping σ²\* under flat between-run EMD (formats replay; pub has the same call sites).
- **Conceptual mismatch** — the pipeline “relies on soft + EMD” in narrative, yet the foundational topic state is hard.
- **Missed geometry** — hard spherical k-means ignores local linear structure that MPPCA was designed to capture (Tipping & Bishop), with k-means as the standard initialisation — not the final model.

**Design principle**: soft is the primary state; hard is a late *view* for consumers that insist on discrete units.

## Detailed Description

### Current vs target

| Layer | Today | Target |
|-------|--------|--------|
| Phrase→topic | Hard k-means `cluster_id` + sklearn / member-mean centroid | MPPCA responsibilities \(r_{ik}\); component means \(\mu_k\) (k-means init, then EM) |
| Stored geometry | Hard assignments + centroid array | Soft responsibility matrix (or equivalent sparse form) + component parameters; hard labels optional derived artefact |
| Document histogram | Hard counts → shares | Sum soft mass per topic (rows of \(R\) aggregated by doc) |
| LLM label / lens prompts | Operate on hard cluster ids + exemplars | Operate on a **hardened view** (e.g. MAP topic, or top-mass exemplars under \(r_{ik}\)) produced at the boundary |
| Soft lenses | PPCA on hard topic centroids; weights \((K \times L)\) | Same maths on MPPCA component means (or soft-aggregated topic reps); weights still topic→lens |
| Document EMD | Hard shares × cosine(\(C\)) | Soft shares × cosine(\(\mu\)) |
| Reporting / paper tables | Hard themes | Harden at export |

### Why MPPCA (not “soft k-means” alone)

K-means initialises component means. EM then fits per-component PPCA (loading + noise) and soft responsibilities. That yields:

- Responsibility-weighted means as the natural centroids (no sklearn vs member-mean fork).
- Local subspaces per topic, commensurate with the lens-level PPCA story already in multilogue CIP-0005.
- A single story: mixture-of-PPCA at **topic** level; mixture-of-PPCA (LLM-partitioned) at **lens** level — with an explicit account of the two noise floors (see below).

### Two σ² knobs (decision at Accept)

| Knob | Role | Rule for a published / multiverse cell |
|------|------|----------------------------------------|
| Topic-level \(\sigma^2_{\mathrm{topic}}\) | MPPCA fit on phrase embeddings; topic factor rank / softness of \(r_{ik}\) | **Fixed** for the run (documented default or profiled once; not re-fit per lens replicate or per document) |
| Lens-level \(\sigma^2_{\mathrm{lens}}\) | Soft lens responsibilities | **Fixed** shared value when scoring mixture weights; σ²\* chosen once by the existing cross-run EMD rule (then held fixed for headline weights) |

**Accepted decision (2026-10-17):** the two floors are **independent**. Topic \(\sigma^2\) is a fixed hyperparameter of the MPPCA fit for that analysis config. Lens \(\sigma^2\) is selected by the current σ²\* procedure (or a multiverse neighbour rule) and then fixed. Do not share one floor across both layers in v1; do not give each lens-mapping replicate its own σ². A later sensitivity arm may vary topic \(\sigma^2\); that is optional, not the unmarked default.

Default numeric topic \(\sigma^2\) (or a short profile grid) is chosen in the multilogue MPPCA backlog task and recorded in concept docs.

### Harden-only boundaries

Hardening is allowed only at:

1. **LLM I/O** — discrete theme units for `label_cluster` / framing-lens grouping (may remain canonical committed mappings per CIP-0013 / REQ-0007 once approved).
2. **Human artefacts** — tables, exemplar lists, paper prose.
3. **Optional multiverse arm** — explicit `assignment=hard_map` vs `soft` for sensitivity, not the unmarked default.

Everything else (histograms, EMD, framing salience, checkpoints used for replay) uses soft state.

### Relationship to interim centroid / σ² harden bugs

Multilogue tasks `2026-10-17_unify-member-mean-centroids` and `2026-10-17_harden-sigma2-flat-emd-selection`, and pub bug `2026-10-17_adopt-member-mean-centroids-and-sigma2-harden`, remain valid **near-term** fixes for the hard-k-means + soft-lens stack. This CIP **supersedes** them as the end state: once soft-throughout lands, sklearn `cluster_centers_` is no longer the topic definition, and flat-EMD selection harden still applies to lens σ²\*. Do not block CIP-0017 design on those tasks completing, but prefer implementing MPPCA topic primitives in multilogue rather than deepening pub-local k-means centroid helpers.

### Where code lives

| Piece | Home |
|-------|------|
| MPPCA fit (k-means init, EM, responsibilities, \(\mu_k\)) | `multilogue.cluster` (or new `multilogue.mppca`) — preferred |
| Soft doc histograms, EMD ground cost on \(\mu\) | `multilogue.distance` (extend CIP-0005) |
| Soft lenses / σ²\* | `multilogue.soft` (already) |
| Pub notebooks / `AddressStage` | Thin: call multilogue; drop local k-means-as-primary paths |
| Harden helpers (`responsibilities_to_labels`, exemplar selection) | multilogue utility; used at LLM/report edges |

Pub should not re-implement PPCA/EM maths locally (same rule as the interim soft-distance adopt tasks).

### Alternatives considered

1. **Keep hard k-means; only unify member-mean centroids** — fixes replay flip; does not address soft-throughout. Retained as interim only.
2. **Soft k-means / fuzzy c-means without PPCA** — soft responsibilities without local subspaces; weaker alignment with lens PPCA and teaching stack.
3. **Phrase→lens MPPCA, skip topics** — removes LLM theme inventory; breaks current paper structure (named themes, cross-cutting entropy per theme). Rejected for this CIP; could be a later experiment.
4. **Full joint EM over topics and lenses** — folds LLM partition into unsupervised EM; abandons committed lens semantics (REQ-0007). Out of scope.

### Impact on artefacts and paper

- Checkpoints: responsibility matrices (and/or component params) replace or augment `cluster_assignments` / `cluster_centroids.npy`.
- Canonical lens mappings: may key on stable component ids after a frozen MPPCA fit; migration note required.
- Sensitivity / multiverse: `k` still meaningful as component count; add soft vs hard-view arm if headline numbers shift.
- Published tables that assumed hard phrases-in-cluster counts need a soft-mass analogue or an explicit hardened recount.

## Backward Compatibility

**Breaking** for consumers that assume hard `cluster_id` as the only topic state. Migration:

- Loaders accept soft checkpoints; hard labels derived when missing.
- Old centroid `.npy` files not bit-identical to MPPCA \(\mu\); treat as obsolete after regen.
- Canonical framing maps may need one deliberate rewrite after the first frozen soft fit (REQ-0007 process).

Interim member-mean unify remains compatible with the old hard stack until this CIP ships.

## Testing Strategy

- Synthetic embeddings with known subspace components: MPPCA recovers means / responsibilities better than hard k-means under overlap.
- Soft histogram rows sum to 1; EMD symmetry / zero diagonal unchanged in spirit.
- Harden view: MAP labels equal `argmax` responsibilities; exemplars deterministic given seed.
- Replay: freeze responsibilities (or params + data hash); fresh fit matches freeze within tol — no sklearn/member-mean fork.
- Lens σ²\*: flat-EMD harden behaviour covered in multilogue; pub thins to that API.
- Optional: notebook smoke on a tiny fixture corpus without live LLM (FakeClient).
